## kubernetes Windows 환경에서 셋팅하는 법

##### cmd에서 아래 명령어 실행

```bash
wsl --install # Unbuntu 설치
wsl.exe -d Ubuntu # Unbuntu 실행
```
___
##### Docker Desktop 설치
[Docker 공식 사이트](https://www.docker.com/products/docker-desktop/)
1️⃣ WSL2 엔진 사용

Docker Desktop → Settings → General

✔ Use the WSL 2 based engine

2️⃣ WSL Integration 켜기 (핵심)

Docker Desktop → Settings → Resources → WSL Integration

👉 Ubuntu 체크 ✔

3️⃣ Docker 실행 확인 (WSL에서)
```bash
docker ps
```
👉 아무 에러 없이 나오면 성공
___

##### ububtu 실행 후, k3d 설치
```bash
curl -s https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh | bash
```

4️⃣ 클러스터 생성
```bash
k3d cluster create mycluster
```

5️⃣ 확인
```bash
kubectl get nodes
```
