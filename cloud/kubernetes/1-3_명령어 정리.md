## 🔥 명령어 정리

#### 🚩 `kubectl apply -f pod.yaml`
- `-f` = file
- `pod.yaml` 파일 내용을 kubernetes에 적용
👉 Kubernetes는 이 YAML을 읽고 Pod가 없으면 새로 만들고, 이미 있으면 변경사항을 반영
___
#### 🚩 `kubectl get pods`
- 현재 네임스페이스의 Pod 목록 조회
ex)
```bash
NAME       READY   STATUS    RESTARTS   AGE
my-nginx   1/1     Running   0          10s
```
- `1/1`: 컨테이너 1개가 준비됨
- `Running`: 실행 중
- `0`: 재시작 횟수
- `10s`: 만든지 10초
___
#### 🚩 `kubectl delete pod my-nginx`
👉 이름이 `my-nginx`인 Pod 삭제
___
#### 🚩 `kubectl run nginx --imgage=nginx`
👉 명령어 한 줄로 Pod를 빠르게 생성(YAML 파일 없이 바로 만들 수 있음)
___
#### 🚩 `kubectl exec -it nginx-pod -- bash`
👉 실행중인 Pod 안으로 들어가서 명령어 실행
##### 옵션 설명
- `exec`: 컨테이너 안에서 명령 실행
- `-i`: 표준입력 유지
- `-t`: 터미널처럼 사용
- `nginx-pod`: Pod 이름
- `-- bash`: bash 셸 실행 (`bash` 안되는 경우 `-- sh`)
___
#### 🚩 `kubectl logs niginx-pod`
👉 Pod 안 컨테이너 로그 출력
___
#### 🚩 `kubectl describe pod my-nginx`
👉 Pod 상세 정보 출력 (`get`보다 훨씬 자세함)
- 어떤 이미지인지
- 어떤 노드에 올라갔는지
- IP가 뭔지
- 이벤트가 뭐 있었는지
- 에러가 왜 났는지
___
#### 🚩 `kubectl run nginx --image=nginx --dry-run=client -o yaml > pod.yaml`
##### `kubectl run nginx --image=nginx`
👉 nginx Pod를 만들어라
##### `--dry-run=client`
👉 실제로 만들지말고, 내 컴퓨터에서 명령 결과만 미리 생성(클러스터에는 안 올림)
##### `-o yaml`
👉 출력 형식을 YAML로 보여달라는 뜻
##### `> pod.yaml`
👉 이 출력 결과를 화면에 보여주지 말고 `pod.yaml` 파일에 저장해라
> nginx Pod를 만들기 위한 기본 YAML 템플릿을 자동으로 생성해서 pod.yaml에 저장하라는 명령어
